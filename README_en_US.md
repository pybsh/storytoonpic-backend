### Introduction
This app allows users to upload photos and generates storytelling and AI-generated images based on those photos. <br/>
It was created to allow young children to take photos and enjoy fairy-tale-like stories about their pictures.

### Key Features
- Image regeneration in crayon style using SDXL and LoRA
- Story generation using LLM
